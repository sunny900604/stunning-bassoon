# stunning-bassoon

굿팝업(GoodPopup) 운영 대시보드 — SBA × 굿윌스토어 × 참여기업 협업 프로그램의 배분·결산·홍보성과·온보딩을 관리하는 단일 파일 웹앱입니다.

`index.html`을 브라우저로 열면 바로 실행됩니다(빌드 불필요). 데이터는 브라우저 `localStorage`에 저장됩니다.

- **종합 대시보드 / 결과보고서**: 결과보고서는 보는 대상(SBA·굿윌스토어·참여기업)에 따라 강조 지표가 달라집니다.
- **지점별 현황 · 기업별 현황 · 배분 관리 · 행사 결산 · 홍보 성과**: 상세 운영 데이터
- **온보딩 진행 · 기증확대 KPI 보드 · 운영 프로세스**: 진행 관리
- **데이터 공백 · 수정 점검**: 원본 데이터에서 발견된 공백·충돌 항목 추적

현재 포함되지 않은 것(다음 단계 후보): 96개사 전체 BD/영업파이프라인(CRM), 구글시트↔영업팀 현장기록 연동, 고객후기 QR 수집, 매장 사진 자료, POP·홍보물 제작 표준 가이드.
