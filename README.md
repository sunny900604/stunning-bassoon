# stunning-bassoon

굿팝업(GoodPopup) 운영 대시보드 — SBA × 굿윌스토어 × 참여기업 협업 프로그램의 배분·결산·홍보성과·온보딩을 관리하는 단일 파일 웹앱입니다.

`index.html`을 브라우저로 열면 바로 실행됩니다(빌드 불필요). 데이터는 브라우저 `localStorage`에 저장됩니다.

- **종합 대시보드 / 결과보고서**: 결과보고서는 보는 대상(SBA·굿윌스토어·참여기업)에 따라 강조 지표가 달라집니다.
- **지점별 현황 · 기업별 현황 · 배분 관리 · 행사 결산 · 홍보 성과**: 상세 운영 데이터
- **온보딩 진행 · 기증확대 KPI 보드 · 운영 프로세스**: 진행 관리
- **데이터 공백 · 수정 점검**: 원본 데이터에서 발견된 공백·충돌 항목 추적

현재 포함되지 않은 것(다음 단계 후보): 96개사 전체 BD/영업파이프라인(CRM), 구글시트↔영업팀 현장기록 연동, 고객후기 QR 수집, 매장 사진 자료, POP·홍보물 제작 표준 가이드.

## 엑셀 연동

사이드바의 **📥 엑셀로 내보내기 / 📤 엑셀 불러오기** 버튼으로 앱과 엑셀 파일을 계속 오갈 수 있습니다.

- **내보내기**: 현재 화면의 모든 데이터를 `기업정보·배분관리·행사결산·홍보성과·온보딩체크·임팩트결산·지점마스터` 7개 시트로 구성된 `.xlsx` 파일로 저장합니다. SBA 제출용, 백업용, 엑셀에서 대량 수정할 때 등에 씁니다.
- **불러오기**: 이 앱에서 내보낸 형식의 `.xlsx` 파일을 다시 올리면, 시트 내용대로 앱 데이터가 전부 교체됩니다(엑셀에서 값을 고친 뒤 다시 불러오는 용도).
- 실시간 양방향 동기화(구글시트 IMPORTRANGE 같은)는 아닙니다 — 정적 파일 기반 앱이라 "내보내기 → 편집 → 불러오기"로 두 형태를 계속 오가며 쓰는 방식입니다.
- 엑셀 처리 라이브러리([SheetJS](https://sheetjs.com))는 `vendor/`에 로컬로 포함되어 있어 인터넷 연결 없이도 동작합니다.
